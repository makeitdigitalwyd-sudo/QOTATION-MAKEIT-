# MakeIt Digital — Quotation Studio

Self-contained web application for creating, editing, and printing MakeIt Digital client quotations.

## Files Included
- `index.html`: Complete offline-ready Quotation Maker application (HTML, CSS, and JavaScript in one file).
- `README.md`: Setup and usage instructions.

## How to Run
1. Extract the ZIP archive to any folder on your computer.
2. Double-click `index.html` to open it in Chrome, Edge, Safari, or Firefox.
3. Click directly on any company field, client detail, deliverable description, unit, quantity, or price to edit inline.
4. Click **Print / Save PDF** in the top bar to print or save a clean A4 PDF.
